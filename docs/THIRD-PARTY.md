# Third-party assets

Lumina's engine has **no runtime dependencies**: every codec and the PSD
implementation live in `src/`. The items below are the only third-party material
shipped in this repository.

## Development dependencies (not shipped in the engine)

| Package | Purpose | License |
|---|---|---|
| `electron` | desktop shell | MIT |
| `electron-builder` | packaging for macOS / Linux / Windows | MIT |
| `puppeteer` | real headless-browser UI tests and screenshots | Apache-2.0 |
| `pngjs` | independent PNG reference used in tests only | MIT |

The packaged desktop application contains Electron and Chromium; their licence
files (`LICENSE.electron.txt`, `LICENSES.chromium.html`) are included in every
release artifact, as required.

## Verification tools (used in CI, never bundled)

| Tool | Purpose | License |
|---|---|---|
| [psd-tools](https://github.com/psd-tools/psd-tools) | independent PSD reader used as the reference for pixel comparisons | MIT |
| [Pillow](https://python-pillow.org/) | second opinion on file validity and ICC handling | MIT-CMU |
| [QOI reference implementation](https://github.com/phoboslab/qoi) (`test/ref/qoi.h`) | byte-exact QOI interop test | MIT |

## Test data

- `tests/psd_files/*` downloaded by `npm run verify:corpus:download` come from the
  psd-tools repository (MIT). They are fetched at run time and are **not**
  redistributed in this repository.
- Demo artwork and screenshots under `docs/screenshots/` are generated by
  `npm run sample` and `npm run screenshot` from this repository's own code —
  they contain no third-party imagery.
